# HSU(한성대) 도구모음집

![HSU 도구모음집 아이콘](./icons/icon128.png)

한성대학교 e-class에서 영상 시청 기간과 과제 제출 기한을 놓치지 않도록 돕는 Chrome 확장 프로그램입니다. 마감 달력, 영상 연속 재생, 메모장 등 학습에 필요한 편의 기능을 제공합니다.

- 설치: [Chrome 웹 스토어](https://chromewebstore.google.com/detail/hsu%ED%95%9C%EC%84%B1%EB%8C%80-%EB%8F%84%EA%B5%AC%EB%AA%A8%EC%9D%8C%EC%A7%91/ceflinnfnijdfpncaaelgjmieknjbabj?hl=ko)
- 사용 사이트: [한성대학교 e-class](https://learn.hansung.ac.kr/)
- 소스 코드: [iamcode04/hsu-toolbox](https://github.com/iamcode04/hsu-toolbox)
- 현재 소스의 확장 프로그램 버전: `3.0.0`
- 라이선스: [MIT](./LICENSE)

## 제작 배경

영상 시청 기간을 놓치거나 과제 제출 기한을 넘겨 늦게 제출하고, 때로는 아예 제출하지 못하는 일을 줄이고 싶어 만들었습니다. 과제와 영상의 마감일을 한눈에 확인할 수 있도록 달력을 추가했습니다.

봐야 할 영상을 매번 클릭하지 않고 이어서 볼 수 있도록 영상 연속 재생 기능을 만들었으며, 시험 범위처럼 중요한 내용을 간단하게 적어 둘 수 있도록 메모장도 함께 만들었습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 메모 | 상단바에서 마크다운을 지원하는 메모장을 열고, 작성 내용을 자동으로 저장합니다. |
| 디데이 | 상단바에 최대 3개까지 등록할 수 있습니다. 이름·날짜·글자색을 설정하고 수정하거나 삭제할 수 있습니다. |
| 남은 기간 | 강의 페이지에서 영상·과제의 시작 전 상태, 마감까지 남은 시간, 기간 종료, 출석·제출 완료 상태를 표시합니다. |
| 시청 진도 | 강의 영상 항목에 학습 시간과 영상 길이를 바탕으로 한 진도율과 진행 막대를 표시합니다. |
| 할 일 개수 | 대시보드의 과목별로 7일 이내 마감인 미제출 과제와 현재 시청 기간에 해당하는 미시청 영상 개수를 표시합니다. 마우스를 올리면 목록과 마감 정보를 볼 수 있습니다. |
| 미시청 영상 | 현재 시청 가능한 미시청 영상을 별도 창에서 마감순으로 확인하고 재생할 수 있습니다. `자동시청`을 선택하면 영상이 끝난 뒤 다음 영상으로 이동합니다. |
| 과제 달력 | 과제와 미시청 영상의 마감일, 제출 완료 상태, 제출한 날을 월별 달력으로 표시합니다. 날짜를 선택하면 상세 목록을 확인할 수 있습니다. |
| 기능 설정 | e-class 왼쪽 메뉴의 `도구모음`에서 각 기능의 표시를 켜거나 끌 수 있습니다. |

## 설치 방법

### Chrome 웹 스토어에서 설치

1. [HSU(한성대) 도구모음집 설치 페이지](https://chromewebstore.google.com/detail/hsu%ED%95%9C%EC%84%B1%EB%8C%80-%EB%8F%84%EA%B5%AC%EB%AA%A8%EC%9D%8C%EC%A7%91/ceflinnfnijdfpncaaelgjmieknjbabj?hl=ko)를 엽니다.
2. **Chrome에 추가**를 누르고 확장 프로그램 추가를 확인합니다.
3. [한성대학교 e-class](https://learn.hansung.ac.kr/)에 로그인하고 페이지를 새로고침합니다.

### 소스 코드로 설치

1. [GitHub 저장소](https://github.com/iamcode04/hsu-toolbox)에서 **Code → Download ZIP**을 선택합니다.
2. 다운로드한 ZIP 파일의 압축을 풉니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 선택하고, `manifest.json`이 들어 있는 폴더를 지정합니다.
6. [한성대학교 e-class](https://learn.hansung.ac.kr/)에 로그인하고 페이지를 새로고침합니다.

소스에 포함된 파일을 사용하는 설치 방법입니다. 확장 프로그램 폴더를 로드하는 절차는 [Chrome 공식 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)를 참고할 수 있습니다.

## 사용 방법

- **상단바:** `메모`를 눌러 메모장을 열거나, `+ 디데이`로 날짜를 등록합니다.
- **대시보드:** 과목별 할 일 개수를 확인하고, `미시청 영상` 또는 `과제 달력`을 열어 전체 목록을 확인합니다.
- **강의 페이지:** 영상·과제 옆의 남은 기간과 영상의 시청 진도를 확인합니다.
- **왼쪽 메뉴:** `도구모음`에서 필요한 기능의 표시를 선택합니다.

미시청 영상 창에서 개별 재생 버튼을 누르면 e-class 영상 창이 열립니다. `자동시청`은 목록의 영상을 한 번에 하나씩 순서대로 재생하며, `중지` 버튼으로 다음 영상으로 이어지는 자동시청을 중단할 수 있습니다.

## 데이터와 표시 기준

- 메모, 디데이, 기능 설정, 과제·영상 정보 캐시와 자동시청 상태는 `chrome.storage.local`에 저장됩니다. 메모와 디데이는 e-class 계정별로 분리해 저장하는 구조가 아닙니다.
- 과제·영상 정보는 로그인한 e-class의 과제 목록과 출석 보고서 등을 읽어 구성합니다. 할 일·미시청 영상·달력에 쓰는 캐시는 30분 동안 재사용될 수 있어, 제출이나 시청 직후의 상태가 바로 반영되지 않을 수 있습니다.
- 여기서 **미시청 영상**은 출석 보고서에서 출석 완료로 표시되지 않은 영상입니다. 일부를 시청한 영상도 포함될 수 있으며, 별도 영상 목록에는 현재 시청 기간에 해당하고 재생 주소를 찾을 수 있는 항목이 표시됩니다.
- **시청 진도**는 출석 보고서의 누적 학습 시간을 영상 길이와 비교해 계산합니다. 반복 시청 시간도 포함되며, 표시되는 진도율은 최대 100%입니다. 출석 완료 여부는 보고서의 출석 상태를 따릅니다.
- 달력의 **제출한 날**은 과제 상세 페이지의 `최종 수정 일시`를 기준으로 표시합니다. 자정 `00:00` 마감은 전날의 `24:00`으로 표시합니다.
- 일반 도구는 로그인 화면과 영상 뷰어 화면을 제외한 e-class 페이지에 적용됩니다. 자동시청용 스크립트는 영상 뷰어에 별도로 적용됩니다.

## 개발 참고

JavaScript, HTML, CSS와 Chrome Extensions Manifest V3를 사용합니다. 메모 편집기는 Tiptap 기반의 번들 파일로 포함되어 있습니다.

현재 저장소에는 `package.json`이나 빌드 스크립트가 포함되어 있지 않습니다. 메모 편집기 번들을 다시 만드는 절차는 추가 설명이 필요합니다.

소스를 수정한 뒤에는 `chrome://extensions`에서 확장 프로그램을 새로고침하고, e-class 페이지도 새로고침해 변경 사항을 확인합니다.
